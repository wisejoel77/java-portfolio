### Beginner Problems Overview
---

#### 1. Getting Started
- **[First Program](FirstProgram.java)** → Prints a simple introductory message.

#### 2. Variables, Input & Basic Calculations
- **[Area Of Rectangle](AreaOfRectangle.java)** → Calculates the area of a rectangle.
- **[Area Of Triangle](AreaOfTriangle.java)** → Calculates the area of a triangle.
- **[Area And Circumference Of A Circle](AreaAndCircumferenceOfACircle.java)** → Calculates the area and circumference of a circle.
- **[Simple Interest](SimpleInterest.java)** → Calculates simple interest.
- **[BMI Calculator](BMICalculator.java)** → Calculates Body Mass Index (BMI).

#### 3. Unit Conversion
- **[Feet To Meters](FeetToMeters.java)** → Converts feet to meters.
- **[Inches To Foot](InchesToFoot.java)** → Converts inches to feet.

#### 4. Character Handling
- **[Character Demo](CharacterDemo.java)** → Demonstrates character and integer literals.
- **[Vowel Or Consonant](VowelOrConsonant.java)** → Determines whether an alphabet is a vowel or a consonant.

#### 5. Conditional Statements
- **[Vote Eligibility Checker](VoteEligibilityChecker.java)** → Checks whether a person is eligible to vote.
- **[Movie Discount Checker](MovieDiscountChecker.java)** → Checks movie ticket discount eligibility based on age.
- **[Concert Entry Checker](ConcertEntryChecker.java)** → Determines concert entry eligibility using multiple conditions.
- **[Leap Year Or Not](LeapYearOrNot.java)** → Checks whether a given year is a leap year.
- **[Max Of Three Numbers](MaxOfThreeNumbers.java)** → Finds the largest of three numbers using if-else statements.
- **[Max Among Three Numbers Using Ternary Operator](MaxAmongThreeNumbersUsingTernaryOperator.java)** → Finds the largest of three numbers using the ternary operator.

#### 6. Switch Statements
- **[Number To Word](NumberToWord.java)** → Converts numbers (1–9) into words.
- **[Switch No Of Days](SwitchNoOfDays.java)** → Displays the number of days in a month using a switch expression.
- **[Switch Grading System V1](SwitchGradingSystemV1.java)** → Assigns grades using a traditional switch statement.
- **[Switch Grading System V2](SwitchGradingSystemV2.java)** → Assigns grades using an improved switch statement.
- **[Switch Grading System V3](SwitchGradingSystemV3.java)** → Assigns grades using Java's modern switch expression.

#### 7. Loops
- **[For Loop Printing Even Numbers](ForLoopPrintingEvenNumbers.java)** → Prints all even numbers within a given range.
- **[For Loop Sum Of Numbers](ForLoopSumOfNumbers.java)** → Calculates the sum of numbers within a given range.
- **[Range Checking While Loop](RangeCheckingWhileLoop.java)** → Continuously validates input using a while loop.
- **[Calculator Using Do While](CalculatorUsingDoWhile.java)** → Menu-driven calculator implemented using a do-while loop.
- **[Password Checker Do While](PasswordCheckerDoWhile.java)** → Repeatedly prompts for the correct password using a do-while loop.
