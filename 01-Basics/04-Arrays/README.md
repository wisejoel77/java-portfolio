### Arrays Overview
---
#### 1. One-Dimensional Arrays
- **[Max Element](MaxElement.java)** → Finds the largest element in an integer array.
- **[Reverse An Array](ReverseAnArray.java)** → Prints the elements of an array in reverse order.
- **[Reverse An Array In Place](ReverseAnArrayInPlace.java)** → Reverses an array without using an additional array.
- **[Two Sum Problem](TwoSumProblem.java)** → Finds the indices of two elements whose sum equals a target value.

#### 2. For-Each Loop
- **[For Each Loop 1](ForEachLoop1.java)** → Calculates the sum of all elements in an integer array using a for-each loop.
- **[For Each Loop 2](ForEachLoop2.java)** → Counts the occurrences of characters in a character array using a for-each loop.
- **[For Each Loop 3](ForEachLoop3.java)** → Prints all even numbers from an integer array using a for-each loop.
- **[For Each Loop 4](ForEachLoop4.java)** → Prints all colors stored in a string array using a for-each loop.
- **[For Each Loop 5](ForEachLoop5.java)** → Demonstrates iterating through an array of objects using a for-each loop.

#### 3. Two-Dimensional Arrays
- **[Printing Array In Matrix Form](PrintingArrayInMatrixForm.java)** → Displays a two-dimensional array in matrix format.
- **[Sum Of Elements In Two D Array](SumOfElementsInTwoDArray.java)** → Calculates the sum of all elements in a two-dimensional array.
- **[Largest Element In Two D Array](LargestElementInTwoDArray.java)** → Finds the largest element in a two-dimensional array.
- **[Transpose Of A Two D Matrix](TransposeOfATwoDMatrix.java)** → Computes the transpose of a matrix.
- **[Matrix Multiplication](MatrixMultiplication.java)** → Multiplies two matrices and displays the resulting matrix.

#### 4. Jagged Arrays
- **[Jagged Array Strings Input And Printing](JaggedArrayStringsInputAndPrinting.java)** → Accepts and displays string data using a jagged array.
- **[Sum Of Elements In Each Row Jagged Array](SumOfElementsInEachRowJaggedArray.java)** → Calculates the sum of elements in each row of a jagged array.
- **[Total Number Of Elements In Each Row In Jagged Array](TotalNumberOfElementsInEachRowInJaggedArray.java)** → Displays the number of elements in each row of a jagged array.
