# 🖥️ Java Portfolio

This repository contains my journey of learning **Java programming**, from the very basics to Object-Oriented Programming, Exception Handling, File I/O, and mini projects.

It serves as both a **learning journal** and a **portfolio**, showcasing my progress through structured examples, practice problems, and real-world console applications.

---

## 📂 Repository Structure

- **002-MiniProjects/** → Collection of Java mini projects that apply the concepts learned throughout the repository.
- **01-Basics/** → Covers Java fundamentals, including beginner problems, pattern programs, methods, arrays, and strings.
- **02-OOP/** → Demonstrates Object-Oriented Programming concepts such as Encapsulation, Inheritance, Polymorphism, Abstraction, Composition, Interfaces, and Dynamic Method Dispatch.
- **03-ExceptionHandling/** → Practice programs covering Java exception handling, from basic `try-catch` blocks to custom exceptions.
- **04-FileIO/** → Programs demonstrating Java file handling using byte streams, character streams, buffered streams, and `RandomAccessFile`.

⭐ This repository is continuously updated as I learn new Java concepts and build more projects.
