# 🛒 Shopping Cart System

A console-based shopping cart system developed using Java's `LinkedList`. The project allows users to add, remove, update, and view items in a shopping cart through a menu-driven application.

## Concepts Used

* LinkedList
* Classes and Objects
* Encapsulation
* Methods
* CRUD Operations
* ListIterator
* Scanner
* Menu-driven Programming

## Features

* Add items to the cart
* Remove items from the cart
* Update item quantity
* Update item price
* View first and last added items
* Display cart and total bill
* Clear the cart
* Exit the program
