# 📚 Library Management System

A console-based library management system developed using Java. The project demonstrates object-oriented programming concepts by managing books, magazines, authors, students, professors, and library operations.

## Concepts Used

* Classes and Objects
* Encapsulation
* Inheritance
* Abstraction
* Polymorphism
* Interfaces
* Method Overriding
* `instanceof`
* Arrays
* Constructors
* Getter and Setter Methods
* Input Validation

## Features

* Add and remove books
* Add and remove magazines
* Display books and magazines
* Store author details for books
* Borrow and return library items
* Allow students to borrow books
* Allow professors to borrow library items
* Display borrowed item details
* Track item availability
