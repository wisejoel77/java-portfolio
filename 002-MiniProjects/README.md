### Mini Projects Overview
---
- **[Shopping Cart System](ShoppingCartSystem/)** → Console-based shopping cart system using Java's `LinkedList` to add, remove, update, and display items while calculating the final bill.
- **[Library Management System](LibraryManagementSystem/)** → Console-based library management system demonstrating object-oriented programming concepts such as inheritance, abstraction, polymorphism, interfaces, encapsulation, and method overriding.
- **[Pizza Ordering System](PizzaOrderingSystem.java)** → Console-based application for ordering pizzas with different sizes and toppings while calculating the final bill.
- **[Coffee Ordering System](CoffeeOrderingSystem.java)** → Console-based coffee ordering application with customizable options and bill calculation.
- **[Number Guessing Game](NumberGuessingGame.java)** → Interactive number guessing game where the user attempts to guess a randomly generated number.
- **[YouTube Channel Name Generator](YouTubeChannelNameGenerator.java)** → Generates creative YouTube channel names based on user input.
